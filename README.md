
Actividad 2: Problemas de búsqueda

Requisitos
Python 3. No necesitas instalar librerías externas.

problema1_grafo_bfs_dfs.py
Modela una red de lugares y encuentra una ruta de A a G con BFS y DFS.
Ejecutar: `python problema1_grafo_bfs_dfs.py`

problema2_laberinto_bfs.py
Busca una ruta de S a M en un laberinto usando BFS.
Ejecutar: `python problema2_laberinto_bfs.py`
